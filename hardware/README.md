<h1 align="center">
  Hardware
</h1>

This directory contains the information and files you need to purchase, manufacture, and assemble parts for your camera.

The following documents will guide you through this process. You can also find these documentation in this project's [GitHub Wiki](https://github.com/JiningLiu/stream-cam/wiki).

**[`GETTING_STARTED.md`](./GETTING_STARTED.md)** outlines the hardware for this project. It includes a part list with links to suppliers, as well as parts that will need to be custom manufactured.

**[`MANUFACTURING.md`](./MANUFACTURING.md)** contains instructions on how to 3D print the accessories for your camera, including the enclosure and mounting system. 

**[`ASSEMBLY.md`](./ASSEMBLY.md)** shows you how to put everything together to finish your live stream camera.
